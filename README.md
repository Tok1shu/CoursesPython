## ВЫУЧИТЬ что сравнивает `is`, а что `==`
Я часто путаю это и в джаве, и так же как и операторы условий `||`, `&&`...
опять же:
`is` сравнивает объекты (ссылки)
`==` сравнивает значения
если не переопределить `__eq__` то будет сравнение по идентичности (`is`)

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p1 = Point(1, 2)
p2 = Point(1, 2)
p3 = p1

print(p1 == p2)  # False, хотя данные (1, 2) одинаковые
print(p1 is p2)  # False, объекты находятся в разных местах памяти
print(p1 == p3)  # True, так как p3 ссылается на тот же объект, что и p1

```

Пример:
```python
def __eq__(self,other):
  return self.id == self.id
```
